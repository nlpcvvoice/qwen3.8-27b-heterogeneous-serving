## 一、先分清:V4.1 Flash 不是 V4 Flash 0731 ⚠️

| 项 | 🔴 V4 Flash 0731(旧,2026-04) | 🆕 V4.1 Flash(新,2026-09-10) |
|---|---|---|
| 总参数 | 284B | **552B 主干 + 196B Engram 记忆 = ~763B** |
| 每 token 激活 | 13B | **prefill 8B / decode 16B** |
| 架构 | MoE + CSA/HCA | **MoE + CED(Compressed Expert Dispatch)** |
| 官方检查点体积 | ~158-167 GB | **~510 GB(48 个文件)** |
| 量化救得动吗 | 能(3-bit → 103GB) | **不能,专家已是 FP4,无法再压** |
| 上下文 | 1M | 1M(输出 393K) |
| 授权 | MIT | MIT |
| API 价 | $0.14/$0.28 每 M | $0.30/$1.20 每 M(off-peak 半价) |

> 结论:**V4.1 Flash 是 512GB 级模型,旧版"128GB 家用机跑得动"的说法对它完全失效。**

## 二、官方检查点到底多大(社区实测)

| 口径 | 体积 | 来源 |
|---|---|---|
| 磁盘占用(HF 下载) | **~510 GB / 48 个文件** | ModemGuides 2026-09-10 |
| 纯内存下限(原样加载) | **~475 GiB(≈510 GB)** | 同上 |
| Engram 表转 FP4 之后 | **~385 GiB(省 25%)** | 社区推算 |
| 量化到 128GB | ❌ 不可能 | 多源一致 |

> 关键洞察:V4.1 的专家权重**出厂即 FP4**,GGUF 量化没有压缩空间——这跟 V4(FP4 专家可进一步压到 3bit)完全是两码事。

## 三、能跑的硬件配置(社区实测集合)

### GPU 服务器路线(12-09 社区最快)

| 配置 | 内存分配 | 实测性能 | 引擎 |
|---|---|---|---|
| **4x DGX Spark**(GB10,TP4) | 约 286GB 加速器 + 190GB Engram 走主机 RAM | **77.2 tok/s 代码 / 52 code / 47 math / 40.5 计数** | SGLang preview,已有人跑通(NVIDIA 论坛 09-10) |
| 单 DGX Spark(GB10) | 128GB 单机 | ❌ 装不下 | — |

> 说明:V4.1 的 **Engram 记忆表可以低带宽异步驻留主机 RAM**,因此 GPU 侧只要 ~286GB,这是官方架构设计红利。

## 五、结论 & 建议(对咱项目)

| 判断 | 内容 |
|---|---|
| 本地部署 V4.1 Flash? | 🔴 家用/普通工作站**不现实**:至少 ~286GB GPU 或 512GB 统一内存,新引擎适配至少数周 |
| 想省钱跑大模型? | 🟢 继续用 **V4 Flash 0731(128GB 机器,103GB 3-bit build)** 或 **Qwen3.8-27B**(当前项目) |
| 想体验 V4.1 能力? | 🟡 走 **API($0.30/$1.20,有 1M 上下文 + 便宜 cache)**,不合算再等社区量化 |
| 监控 | ⏳ 盯 SGLang preview 背后的 4x DGX Spark 教程三星化 / unsloth 是否出 calibrated 版 |

### 一句话总结

> **V4.1 Flash 官方 510GB、出厂 FP4、无量化余量 → 本地门槛 ≈ 4x DGX Spark 或 512GB 统一内存;发布当天只有 SGLang preview 能跑。要免费本地用,不如守旧版 V4 Flash 0731 或 27B。**
