## 核心一句话

> **我在免费硬件上搭的这套 TPU+GPU 双引擎服务,和公司里跑 vLLM/Triton + API 网关 + 可观测栈的架构是"1:1 同构"的——攒的每一块积木,在大厂都是一样的名字。**

## 逐块对照(小朋友版:积木 → 大楼)

| 我家积木(本项目) | 公司大楼(商业环境) | 是否真的一样 |
|------------------|--------------------|--------------|
| TPU 跑 vLLM bf16 | 商业 **vLLM / Triton** 推理引擎 | ✅ 同一套引擎,连启动参数都同款 |
| GPU 跑 llama.cpp | 边缘用小模型推理 | ✅ 业界通用做法 |
| **router.py** 自动选主/备 + 转发 | **API Gateway**(Envoy/Kong/nginx) | ✅ 同款职责:路由+限流+鉴权 |
| **controller.py** 健康检查+自动切换 | **K8s liveness/readiness + failover** | ✅ 心跳→探活→自动切换,一个动作不差 |
| **OpenAI /v1 接口** | 全行业 **OpenAI 兼容协议** | ✅ 客户机直接换 base_url 就能用 |
| **current_services.json** 自动登记端点 | **服务注册中心**(Consul/etcd) | ✅ 服务上线→自动登记→被路由发现 |
| ntfy 心跳+阶段事件 | **Prometheus + Alertmanager** 告警 | ✅ 出问题先钉住再决策 |
| **记账本**(MLflow/Langfuse) | **可观测栈**(trace + metric + log) | ✅ 延迟/字数/成本/判分全落库 |
| **私有 dataset 存模型** | **模型仓库/制品库**(Model Registry) | ✅ 版本号+私有访问,一模一样 |
| **P3 引擎缓存** | **CI 产物缓存**(镜像仓库/编译缓存) | ✅ 不重测不重编,复用产物 |
| Locust 压测 5→50VU | **压测平台** + 线上流量回放 | ✅ 同样看 RPS/TTFT/p95/错误率 |
| 探针/断言/判分 | **评估管线**(eval as code) | ✅ 出题、判分、留档,自动跑 |

## 面试官版:为什么说"1:1"

| 面试官问 | 我答 |
|----------|------|
| "你做过生产吗?" | 我按生产的每一层搭了同构的东西:网关、探活、切换、注册、可观测、缓存、压测 |
| "是玩具吗?" | 不是——引擎就是 vLLM/llama.cpp 正主,协议是 OpenAI 兼容原生,不是玩具包装 |
| "凭什么?" | 每个层都有运行日志/CSV/断言为证,可复查 |
| "商业精髓是什么?" | **同一套能力,换个硬件和规模就是人家的系统**——没有"重学"成本 |
