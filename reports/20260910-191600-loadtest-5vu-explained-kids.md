# 考试报告:5 个小朋友同时提问,表现如何?

| 日期 | 2026-09-08 | 对象 | 小朋友能听懂 |
|---|---|---|---|
| 项目 | Locust 压测 (5 VU) | 引擎 | TPU(vLLM bf16) vs GPU(llama.cpp Q4) |
| 看 | `loadtest/` 目录 | 一行结论 | TPU 秒答,0 错误 |

## 考试怎么考的

```
5 个"小朋友"(虚拟用户)同时举手提问 🖐️🖐️🖐️🖐️🖐️
每人休息 0.4~2.4 秒再问下一个(模拟真人)
每道题:有的要答案(不流式)、有的要边说边出(流式,6:3 比例)
共问 70 秒,问 24 道真人会问的问题(代码/翻译/数学/长文/工具调用)
```

## 成绩单(TPU vs GPU)

| 指标 | TPU v5e-8 | GPU 2xT4 | 领先 |
|------|-----------|----------|------|
| 总提问数 | 161 题 | 14 题 | TPU 11.5x |
| 每秒处理 | 2.36 题 | 0.21 题 | TPU 11x |
| **第一个字等待(TTFT)** 中位数 | **125 ms** | 2.9 秒 | TPU 23x |
| **TTFT p95**(95% 都在这个数内) | **172 ms** | 9.4 秒 | TPU 55x |
| 答完全题中位数 | 571 ms | 16.6 秒 | TPU 29x |
| **出错率** | **0%** | **0%** | 平手 ✅ |

## 这些数字"翻译"成小朋友语言

| 数字 | 感觉 | 类比 |
|------|------|------|
| 125 ms | 眼睛眨一下 | 你刚举手,老师已经开口答了 😲 |
| 172 ms | 又一次眨眼 | 连想都不用想,张口就来 |
| 0% 错误 | 全对 | 问 161 题,161 题都有答案 👍 |
| GPU 2.9s | 深吸一口气 | 老师要翻开书慢慢查才开口 |
| 为什么 TPU 快 | vLLM 连续批处理+高速内存 | 老师同时看 4 本作业,还边看边写 |

## 0% 错误怎么看?

| 错误类型 | 结果 |
|----------|------|
| 超时或连不上 | 0 |
| 网络断开/返回错误码 | 0 |
| 流式没吐字/空回复 | 0 |
| 结论 | 5 人并发完全不打架 ✅ |

## 看哪些文件

| 文件 | 内容 |
|------|------|
| `loadtest/tpu_stats.csv` / `gpu_stats.csv` | Locust 官方成绩单(请求数/百分位) |
| `loadtest/ttft_tpu.csv` | TPU 每道题的"第一个字等待"(100 题全记录) |
| `loadtest/ttft_gpu.csv` | GPU 每道题(9 题) |
| 报告 | `20260908-182230-locust-loadtest-tpu-gpu.md` |

## 我们是怎么证明"没作弊"的

| 取证 | 说明 |
|------|------|
| 完整原始 CSV | 每题 TTFT 都留着,可复查 |
| Locust 官方统计 | 第三方工具,非自写脚本 |
| 双引擎同天同题库 | TPU/GPU 同一个 24 题库,公平对比 |
