# 记账本 选择题 — Langfuse 还是 MLflow?

| 日期 | 2026-09-10 | 对象 | 小朋友能听懂 |
|---|---|---|---|
| 问题 | 两个都要装吗? | 谁负责什么? | 装在哪?隐私怎么破? |

## 一句话答案

> **记账本 = 每次请 AI 干活,都记一笔账(谁问的、花了多少字、等了多久、答对没)。**
> Langfuse 是"AI 专用账本",MLflow 是"所有机器学习的大账本"。**只装一个就够,推荐先装 MLflow**。

## Langfuse vs MLflow 对比

| 项目 | Langfuse 🖍️ | MLflow 📚 |
|------|--------------|-----------|
| 擅长什么 | 专记 AI 对话账(每一问一答、工具调用、打钩判分) | 记所有实验账(训练、模型版本、评估、还可记 AI 对话) |
| 界面好看吗 | 极好看,Prompt 版本/判分面板现成 | 够用,侧重实验对比与模型登记 |
| 安装麻烦度 | 麻烦,要数据库(Docker+Postgres) | 简单,一条 pip 命令就装好 |
| 占内存 | 重(数据库服务常驻) | 轻(SQLite 一个文件) |
| 本机隐私 | 数据留本机(自托管)或发云端(付费) | 数据 100% 留在本机文件里 |
| 免费 | 自托管免费,云版要钱 | 完全免费开箱即用 |

## 推荐:只装 MLflow(现在)

| 理由 | 说明 |
|------|------|
| 装哪 | 装进 `./Venv`(项目专用环境,不污染系统) |
| 数据存哪 | `./tmp/mlflow.db`(一个小文件,本机私密) |
| 耗多少资源 | 15Gi 内存的笔记本完全跑得动 |
| 负责哪些账 | ① 每次请求一行 span ② bf16 vs Q4 两个模型版本登记 ③ 判分/评估结果落库 |
| 什么时候升级 Langfuse | 等想上"对话可视化面板 + Prompt 版本管理"时,再补装(写成附录 B 用 Docker 部署) |

## 分工表(如果以后两台都装)

| 组件 | 负责记账 | 不负责 |
|------|----------|--------|
| MLflow | 实验对比、模型版本登记、评估分数落表 | 好看的大屏对话流 |
| Langfuse | 对话流大屏、Prompt 版本对比、判分面板 | 训练实验对比 |

## 隐私怎么破 (红线)

| 数据 | 处理方式 |
|------|----------|
| 请求内容/prompt | 默认只记脱敏摘要,完整内容不进账本(除非你同意) |
| API Key / Token | 一律不记,只记掩码 `sk-abc…xyz` |
| 端口 | 只监听 `127.0.0.1`(本机),不开公网 |
| 外部服务 | 不向任何云发数据;MLflow 完全离线运行 |

## 🟢 可以开工(0 配额)

| 步骤 | 命令/动作 |
|------|-----------|
| 1 安装 | `./Venv/bin/pip install mlflow` |
| 2 启动 | `mlflow server --backend-store-uri sqlite:///tmp/mlflow.db --default-artifact-root ./tmp/mlflow-artifacts --host 127.0.0.1` |
| 3 埋点 | `app/router.py` 每转发一次请求 → 记一个 span(延迟/字数/是否流式) |
| 4 看板 | 浏览器开 `http://127.0.0.1:5000` |
